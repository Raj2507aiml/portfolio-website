# Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my skills, projects, education, certifications, and achievements as a Computer Science (AI & ML) student. The website serves as my digital portfolio for recruiters, collaborators, and fellow developers.

## 🌐 Live Demo

**Website:** https://raj2507aiml.github.io/portfolio-website/

## ✨ Features

* 👋 Interactive hero section
* 👨‍💻 About Me
* 🛠️ Technical Skills
* 🚀 Featured Projects
* 🎓 Education
* 📜 Certifications
* 📞 Contact Section
* 📱 Fully Responsive Design
* ⚡ Smooth scrolling and animations
* 🌙 Modern and clean UI

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/raj2507aiml/portfolio-website.git
```

### Navigate to the project

```bash
cd portfolio-website
```

### Run locally

Simply open `index.html` in your browser, or use a local development server such as VS Code Live Server.
